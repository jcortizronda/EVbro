¿Ayudas a mejorar EVBro?

Este servidor puede enviar una vez al día un informe anónimo al proyecto: versión, qué funciones se usan y los fallos que haya registrado. Sirve para encontrar y corregir errores. No lleva nombres, usuarios, matrículas, VIN, posiciones, viajes ni importes. Dentro puedes ver el informe exacto y cambiarlo cuando quieras en la pestaña Servidor.

¿Conectas al catálogo del proyecto?

El catálogo de consumibles (qué aceite, filtros o escobillas lleva cada coche) puede ser solo el de este servidor o el que comparten los propietarios de EVBro. Si lo conectas, se descarga una vez al día y las piezas que propongan tus usuarios llegan también a él, sin su nombre. Este servidor se da de alta solo, con un clic, y lo puedes cambiar cuando quieras en la pestaña Catálogo.

          Origen del catálogo de este servidor

          «Propio»: solo lo que apruebas aquí. «En línea»: además se descarga a diario el catálogo de otro servidor EVBro y las propuestas de tus usuarios se envían también a su cola. Para el catálogo del proyecto basta con el botón «Conectar» (o con pegar la clave que te hayan dado, ebc_…); para otro servidor, pega el enlace completo (https://servidor#clave). La clave se guarda cifrada y no se vuelve a mostrar. Sin clave válida, el servidor sigue con su catálogo propio.

          Un clic: este servidor se da de alta solo y no hace falta pedir ninguna clave.

          Claves para otros servidores

          Cada clave deja a otra instalación de EVBro leer tu catálogo aprobado y enviarte propuestas, que verás en la cola de arriba con la nota de la clave (nunca con una persona). La clave se enseña una sola vez, como enlace; si pones la URL pública de este servidor, el enlace sale completo.
